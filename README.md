## 📂 Projetos em Destaque

### 📊 [Análise de Dados de Vendas com Python](https://github.com/lubj9/ProjetoVendasEcommerce)
Simulação de análise de vendas para suporte à tomada de decisões estratégicas, utilizando **Python, pandas e matplotlib**. Inclui cálculo de faturamento total, identificação de categorias com maior volume de vendas, análise de produtos rentáveis, desempenho por região e evolução das vendas ao longo do tempo.

**Tecnologias:** `Python` `Pandas` `Matplotlib`

---

### 🎬 [Sistema de Gerenciamento de Dados para Plataforma de Streaming](https://github.com/lubj9/ProjetoStreamingBancoDeDados)
Sistema de banco de dados relacional para gerenciamento de usuários, conteúdos, assinaturas, histórico de visualizações e avaliações. Atuei na modelagem conceitual e lógica, definição de relacionamentos e implementação de consultas SQL, aplicando conceitos de **normalização, integridade referencial e otimização de consultas**.

**Tecnologias:** `SQL` `PostgreSQL` `MySQL` `MER` `Normalização` `Git`

---

### 🌳 [Projeto Netflix BST - Estrutura de Dados em Java](https://github.com/lubj9/ArvoreBSTdataScience)
Aplicação em **Java** para armazenar, organizar e analisar dados de títulos da Netflix utilizando **Árvore Binária de Busca (BST)**. Realiza leitura de arquivos CSV, inserção e busca eficiente de registros, percursos da árvore (pré-ordem, em ordem, pós-ordem) e geração de análises estatísticas.

**Tecnologias:** `Java` `POO` `Estruturas de Dados` `Manipulação de Arquivos`
